Context

When enabled, AskLocal may briefly open hidden search tabs, read the visible result snippets/posts, then close them.

AskLocal uses one universal link extractor across every engine, so any selection works. Pick one or more; priority runs top to bottom. Google and Bing open a brief background tab to render their results.

How many rounds of tool calls (search, get, analyze) the model can make before being asked to answer from gathered context. Higher allows deeper research but takes longer; small local models rarely need more than 6.

How many posts/pages the model may open in one research turn (batch get or several get calls together). The model is told this limit. Cached re-reads do not count.

Set this to the context length your model server actually uses (LM Studio: the loaded model's Context Length; llama-server: -c; Ollama: num_ctx / OLLAMA_CONTEXT_LENGTH). AskLocal fits the system prompt, tools, chat history, post context, and tool results inside it, trims the least important context first, and leaves room for the answer. If it is set higher than the server's real limit, some servers silently cut the prompt.

Lower keeps answers closer to the sources (0.2–0.4 suits most local models). Leave empty to use the provider's default. Models that only accept their default temperature are detected and retried without it.

Media Analysis

Uses a model from your list above. Prefer a vision-capable model.

Used only for the text-only merge when Parallel video chunks is above 1. Prefer a larger-context text model; vision models often cannot fit the merge prompt.

Uses a model from your list above. Prefer a vision-capable model.

Videos are sent as timestamped image arrays plus detected subtitles. Near-duplicate frames are culled before analysis. Defaults favor token efficiency (1s interval, 12 frames/min, max 36). Lower intervals capture more detail and cost more; the minimum is 0.2 seconds. Set max sampled video frames to 0 for no limit. Frames per minute scales the frame count with video length, then capped by the max sampled frames limit; use 0 to rely on the interval only. Seconds per video chunk splits longer clips into time windows (default 30s). Parallel video chunks = 1 analyzes windows in order with continuity notes (no extra merge). Values above 1 analyze multiple windows at once with the Video model, then the Video merge model (text-only, defaults to your main text model) unifies them.

Uses a model from your list above. Prefer an OpenAI-compatible model that accepts audio input.

When video analysis runs, AskLocal extracts audio when subtitle coverage is weak or missing, and analyzes it alongside the visuals. Solid detected captions skip the separate audio pass to save tokens. One merge pass (Video merge model) combines both into a single audiovisual report when audio runs. Audio windows follow Seconds per video chunk. Requires an OpenAI-compatible audio-input model.

Performance

Local runs one model call at a time, which suits a single GPU. API runs up to 12 vision and 6 audio calls at once, captures 3 videos side by side, analyzes video windows 6 at a time and analyzes up to 6 videos and 16 images per post. Loads the thread and analyzes its media while you choose a question, so the answer starts sooner. This uses model calls even if you close the panel without asking.

If you stop an answer or close the panel, media analysis that has already started keeps going and is saved. Asking about the same media later, including reposts and quotes of it, is then instant.

Diagnostics

Keeps the last 40 thread responses AskLocal reads from X, so they can be exported and used to check AskLocal's parsing when X changes its format. They contain the text and public profile data of the posts you opened, and they stay on this device unless you export them.
